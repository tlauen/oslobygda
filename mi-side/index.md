# Mi side

{% if site.mi_side_publisert %}

På Mi side kan du sjå medlemskapen din, oppdatere kontaktopplysningane dine og
betale medlemspengar når kontingentåret er ope.

[Logg inn på Mi side](https://bygdelista.oslobygda.no/mi-side)

Bruk e-postadressa du er registrert med. Du får ein eingongskode som du skriv
inn på nettsida. Du treng ikkje passord eller å trykkje på innloggingslenkjer i e-post.

Har du mist tilgangen til den registrerte adressa eller treng hjelp, kontakt
[folk@oslobygda.no](mailto:folk@oslobygda.no).

{% else %}

Kontakt [folk@oslobygda.no](mailto:folk@oslobygda.no) om du vil sjå eller rette
medlemsopplysningane dine.

{% endif %}
